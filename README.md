# GitHub Manager — Веб-интерфейс для управления репозиториями

[![PHP](https://img.shields.io/badge/PHP-7.4+-blue.svg)](https://www.php.net/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Красивый и функциональный веб-интерфейс для работы с GitHub через API. Позволяет управлять репозиториями, просматривать ветки и создавать **неперетираемые копии** (форки) репозиториев прямо из браузера.

## ✨ Возможности

### 🔐 Авторизация
- Вход с использованием GitHub Personal Access Token
- Безопасное хранение токена в сессии PHP
- Возможность выхода из аккаунта

### 📁 Репозитории
- Просмотр всех ваших репозиториев на GitHub
- Отображение информации: описание, язык программирования, звёзды, форки
- Быстрый переход к репозиторию на GitHub
- Просмотр всех веток репозитория

### 🍴 Создание форков (копий)
- **Важно:** Создаётся полная копия репозитория в вашем аккаунте
- Копия не перетирает оригинал — это независимый репозиторий
- Можно указать своё имя для нового репозитория
- Весь контент (файлы, история коммитов) копируется автоматически

### 🎨 Интерфейс
- Современный адаптивный дизайн
- Поддержка мобильных устройств (свайпы для переключения вкладок)
- Тёмная/светлая тема через CSS переменные
- Анимации и плавные переходы
- Уведомления о действиях

## 🚀 Установка

### Требования
- PHP 7.4 или выше
- Расширения PHP: `curl`, `json`
- Git (установлен на сервере)
- Веб-сервер (Apache/Nginx)

### Шаг 1: Клонирование проекта

```bash
git clone <URL-вашего-репозитория> github-manager
cd github-manager
```

### Шаг 2: Настройка веб-сервера

#### Apache
Убедитесь, что включён mod_rewrite и файл `.htaccess` доступен:

```apache
# В конфигурации виртуального хоста
<Directory /path/to/github-manager>
    AllowOverride All
    Require all granted
</Directory>
```

#### Nginx
Пример конфигурации:

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /path/to/github-manager;
    index index.php;

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/var/run/php/php7.4-fpm.sock;
    }

    location ~ /\.git {
        deny all;
    }
}
```

### Шаг 3: Получение GitHub Token

1. Перейдите на GitHub → Settings → Developer settings → Personal access tokens
2. Нажмите "Generate new token"
3. Выберите разрешения:
   - `repo` — полный доступ к репозиториям
   - `user` — информация о пользователе
4. Скопируйте полученный токен

⚠️ **Важно:** Никогда не передавайте токен третьим лицам!

## 📖 Использование

### Первый вход
1. Откройте `index.php` в браузере
2. Введите ваше имя пользователя GitHub
3. Вставьте полученный токен
4. Нажмите "Войти"

### Работа с репозиториями
- **Вкладка "Репозитории"** — список ваших репозиториев
- **Вкладка "Мои форки"** — список созданных вами форков

### Создание копии репозитория (форка)

1. Найдите нужный репозиторий в списке
2. Нажмите кнопку **"Создать форк"**
3. Подтвердите создание
4. Через несколько секунд копия появится в вашем аккаунте

### Как это работает технически?

При создании форка происходит следующее:

```
1. Создаётся пустой репозиторий в вашем аккаунте GitHub через API
2. Исходный репозиторий клонируется во временную директорию на сервере
3. Инициализируется новый Git с историей коммитов
4. Все файлы пушатся в ваш новый репозиторий
5. Временные файлы удаляются
```

**Преимущества такого подхода:**
- ✅ Копия не связана с оригиналом (не перетирается при обновлениях)
- ✅ Сохраняется полная история коммитов
- ✅ Вы становитесь полным владельцем копии
- ✅ Можно вносить любые изменения без ограничений

### Просмотр веток
1. Нажмите кнопку **"Ветки"** на карточке репозитория
2. Откроется модальное окно со списком всех веток
3. Кликните на ветку, чтобы открыть её на GitHub

## 🔧 Конфигурация

### Переменные окружения (опционально)

Вы можете установить токен напрямую в `index.php`:

```php
$github_token = 'your_token_here';
$github_username = 'your_username_here';
```

Но рекомендуется использовать форму входа для безопасности.

## 🛡️ Безопасность

- Токен хранится только в сессии PHP на сервере
- Все запросы к GitHub API идут через HTTPS
- HTML-вывод экранируется для защиты от XSS
- Имена репозиториев валидируются перед использованием
- Временные файлы удаляются после завершения операций

### Рекомендации
- Не размещайте проект на публичном хостинге без дополнительной защиты
- Используйте HTTPS для вашего веб-сервера
- Регулярно обновляйте токены доступа
- Ограничьте доступ к директории `.git`

## 🐛 Решение проблем

### Ошибка "Неверный токен доступа"
- Проверьте, что токен действителен
- Убедитесь, что у токена есть нужные разрешения
- Создайте новый токен при необходимости

### Ошибка при создании форка
- Проверьте, что Git установлен на сервере
- Убедитесь, что у PHP есть права на выполнение системных команд
- Проверьте логи веб-сервера

### Репозиторий уже существует
- При создании копии имя должно быть уникальным
- Удалите существующий репозиторий с таким именем или выберите другое
